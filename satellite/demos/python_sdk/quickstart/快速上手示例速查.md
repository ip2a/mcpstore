## 🔍 增强项说明

### Agent 模式（`+agent`）

**特点**：
- 使用 `store.for_agent(agent_name)` 替代 `store.for_store()`
- 为特定 Agent 管理独立的服务配置和工具调用
- 支持多 Agent 隔离

**适用场景**：
- 需要为不同 Agent 配置不同服务
- 多 Agent 协作场景
- Agent 级别的服务管理

---

### Redis 缓存（`+redis`）

**特点**：
- 使用 Redis 作为共享缓存后端
- 支持多进程/多实例共享数据
- 需要配置 Redis 连接信息

**适用场景**：
- 多进程部署
- 需要持久化缓存
- 分布式场景

**配置来源**：`example_utils.ExampleConfig`

---

### LangChain 增强（`+langchain`）

**特点**：
- Step 7 替换为 LangChain Agent 流程
- 工具调用由 Agent 自动决策
- 需要配置 LLM（通过 `ExampleConfig.get_llm_config()`）

**适用场景**：
- 需要智能工具选择
- 自然语言交互
- Agent 自主决策场景

**依赖**：
- LangChain 相关库
- LLM API 配置

---

### Studio 服务（`+studio`）

**特点**：
- 使用 STDIO 服务（本地进程）
- 服务配置使用 `command` + `args` 格式
- 服务名称通常为 `mcpstore-wiki`

**适用场景**：
- 本地服务开发测试
- STDIO 协议服务
- 不需要 HTTP 服务

**默认配置**：
```python
{
    "command": "python",
    "args": ["/home/yuuu/app/2025/2025_6/mcpstore/wiki/mcp_service_wiki_studio.py"],
    "env": {}
}
```

## 📝 文件命名规则

所有文件遵循统一命名规范：

```
标准链路+[agent]+[redis]+[langchain]+[studio].py
```

**规则**：
1. 基础文件名：`标准链路.py`
2. 增强顺序固定：`agent` → `redis` → `langchain` → `studio`
3. 使用加号（`+`）连接所有增强项
4. 所有组合都必须包含 `标准链路` 前缀

## 🚀 使用说明

### 运行示例

所有示例文件都可以直接运行：

```bash
# 使用 uv 运行（推荐）
uv run python 标准链路.py

# 或运行其他增强版本
uv run python 标准链路+agent+redis.py
```

### 配置要求

**Redis 增强**：
- 需要配置 `example_utils.ExampleConfig` 中的 Redis 连接信息
- 确保 Redis 服务已启动

**LangChain 增强**：
- 需要配置 `example_utils.ExampleConfig` 中的 LLM API 信息
- 确保相关 LangChain 库已安装

**Studio 增强**：
- 需要确保服务脚本路径正确
- 确保 Python 环境可执行对应脚本
