# 二级增强规范指南

本指南说明如何在**标准链路**（基础模式）之上叠加第一层延伸（二级增强），形成各种组合模式。

## 1. 核心原则

1. **标准链路是基础**：所有二级增强都基于 `标准链路.py` 的结构和步骤
2. **增强是叠加的**：可以在标准链路上叠加一个或多个增强，形成组合模式
3. **命名规范**：文件名应反映叠加的增强，如 `标准链路_redis.py`、`标准链路agent.py`、`标准链路agent_redis.py`
4. **保持结构一致**：所有增强版本都应保持标准链路的步骤结构，只修改相关部分

---

## 2. 四种基础增强模式

### 2.1 Agent 模式增强（`for_store` → `for_agent`）

**适用场景**：需要为特定 Agent 管理独立的服务配置和工具调用

**核心变化**：
- 所有 `store.for_store()` 改为 `store.for_agent(agent_name)`
- 需要在文件开头定义 `agent_name` 变量
- `reset_config()` 仍使用 `store.for_store().reset_config()`（全局清理）

**标准修改点**：

```python
# Step 1: 保持不变
store = MCPStore.setup_store(debug=False)

# Step 2: reset_config 保持使用 for_store（全局清理）
store.for_store().reset_config()

# Step 3: show_config 改为 for_agent
config = store.for_agent(agent_name).show_config()

# Step 4-7: 所有操作改为 for_agent
store.for_agent(agent_name).add_service(service_config)
store.for_agent(agent_name).wait_service(service_name)
services = store.for_agent(agent_name).list_services()
tools = store.for_agent(agent_name).list_tools()
tool_result = store.for_agent(agent_name).call_tool(tool_name, tool_params)

# Step 8: show_config 改为 for_agent
config = store.for_agent(agent_name).show_config()

# Step 9: reset_config 保持使用 for_store（全局清理）
store.for_store().reset_config()
```

**文件命名**：`标准链路+agent.py`

---

### 2.2 Redis 缓存增强（内存缓存 → Redis 缓存）

**适用场景**：需要使用 Redis 作为共享缓存后端，支持多进程/多实例共享数据

**核心变化**：
- Step 1 初始化时添加 `cache=redis_config` 参数
- 需要导入 `RedisConfig` 和 `ExampleConfig`
- 打印信息中说明使用 Redis 后端

**标准修改点**：

```python
# 导入部分添加
from mcpstore.config import RedisConfig
from example_utils import setup_example_import, ExampleConfig

# Step 1: 添加 Redis 配置
print("\n[Step 1] Initialize MCPStore with Redis Backend")
redis_config = RedisConfig(
    host=ExampleConfig.REDIS_HOST,
    port=ExampleConfig.REDIS_PORT,
    password=ExampleConfig.REDIS_PASSWORD,
    namespace=ExampleConfig.REDIS_NAMESPACE,
    db=ExampleConfig.REDIS_DB
)
store = MCPStore.setup_store(debug=False, cache=redis_config)
print(f"  ├─ Redis Host: {ExampleConfig.REDIS_HOST}")
print(f"  ├─ Redis Port: {ExampleConfig.REDIS_PORT}")
print(f"  ├─ Namespace: {ExampleConfig.REDIS_NAMESPACE}")
print("  └─ ✓ MCPStore instance created successfully (Redis Backend)")
```

**文件命名**：`标准链路+redis.py`

### 2.3 LangChain 增强（手动 call_tool → LangChain Agent）

**适用场景**：需要使用 LangChain Agent 自动决策和调用工具，而非手动调用

**核心变化**：
- Step 7 的 `call_tool` 替换为 LangChain Agent 流程
- 需要导入 LangChain 相关模块和 `ExampleConfig`
- 添加 LLM 初始化步骤
- 添加 Agent 构建和执行步骤

**标准修改点**：

```python
# 导入部分添加
from langchain.agents import create_agent
from langchain_core.messages import HumanMessage
from langchain_openai import ChatOpenAI
from example_utils import setup_example_import, ExampleConfig

# Step 7: 替换为 LangChain 流程
print("\n[Step 7] Setup LangChain Agent and Call Tools")

# 7.1: 加载 LangChain 工具
tools = store.for_store().for_langchain().list_tools()
print(f"  ├─ Total LangChain Tools: {len(tools)}")
for idx, tool in enumerate(tools, 1):
    print(f"  │   ├─ [{idx}] {tool.name}")
    print(f"  │   │   └─ Description: {tool.description[:80]}...")

# 7.2: 初始化 LLM
llm_config = ExampleConfig.get_llm_config()
llm = ChatOpenAI(
    temperature=0,
    model=llm_config["model"],
    api_key=llm_config["api_key"],
    base_url=llm_config["api_base"],
)
print(f"  ├─ LLM Model: {llm_config['model']}")

# 7.3: 构建 Agent
agent_graph = create_agent(
    model=llm,
    tools=tools,
    system_prompt="You are a helpful assistant that can call tools when needed."
)
print("  ├─ Agent created successfully")

# 7.4: 执行查询
user_query = "Get mcpstore documentation URL"
inputs = {"messages": [HumanMessage(content=user_query)]}
print(f"  ├─ User Query: {user_query}")
print("  └─ Executing Agent...")

final_state = agent_graph.invoke(inputs)
final_messages = final_state.get("messages", [])
final_answer = final_messages[-1].content if final_messages else "(No result)"
print(f"  └─ ✓ Agent execution completed")
print(f"  └─ Result: {final_answer}")
```

**文件命名**：`标准链路+langchain.py`

### 2.4 Studio 服务增强（HTTP 服务 → STDIO 服务）

**适用场景**：使用本地 STDIO 服务（Studio 模式）而非远程 HTTP 服务

**核心变化**：
- Step 4 的 `service_config` 从 `url` 改为 `command` + `args` + `env`
- 服务名称通常使用 `service_name`（如 `mcpstore-wiki`）
- 打印信息中说明使用 Studio 模式

**标准修改点**：

```python
# Step 4: 修改服务配置
print("\n[Step 4] Add MCP Service (Studio Mode)")
agent_name = "demo_agent"
service_name = "mcpstore-wiki"  # Studio 服务通常有特定名称
service_config = {
    "mcpServers": {
        service_name: {
            "command": "python",
            "args": [
                "/path/to/mcp_service_wiki_studio.py"  # 使用实际路径
            ],
            "env": {}
        }
    }
}
store.for_store().add_service(service_config)
print(f"  ├─ Service Name: {service_name}")
print(f"  ├─ Service Type: STDIO (Studio Mode)")
print(f"  ├─ Command: {service_config['mcpServers'][service_name]['command']}")
print(f"  ├─ Args: {service_config['mcpServers'][service_name]['args']}")
print("  └─ ✓ Service added successfully")
```

**文件命名**：`标准链路+studio.py`

## 3. 组合增强规则

### 3.1 命名规范

多个增强组合时，文件名使用加号（`+`）拼接，格式为：
```
标准链路+[agent]+[redis]+[langchain]+[studio].py
```

**规则**：
1. 基础文件名：`标准链路.py`（无任何增强）
2. 增强顺序固定：`agent` → `redis` → `langchain` → `studio`
3. 使用加号（`+`）连接所有增强项
4. 所有组合都必须包含 `标准链路` 前缀

**完整组合列表**（共16个文件）：

**单增强（4个）**：
- `标准链路+agent.py`：Agent 模式
- `标准链路+redis.py`：Redis 缓存
- `标准链路+langchain.py`：LangChain
- `标准链路+studio.py`：Studio 服务

**双增强（6个）**：
- `标准链路+agent+redis.py`：Agent + Redis
- `标准链路+agent+langchain.py`：Agent + LangChain
- `标准链路+agent+studio.py`：Agent + Studio
- `标准链路+redis+langchain.py`：Redis + LangChain
- `标准链路+redis+studio.py`：Redis + Studio
- `标准链路+langchain+studio.py`：LangChain + Studio

**三增强（4个）**：
- `标准链路+agent+redis+langchain.py`：Agent + Redis + LangChain
- `标准链路+agent+redis+studio.py`：Agent + Redis + Studio
- `标准链路+agent+langchain+studio.py`：Agent + LangChain + Studio
- `标准链路+redis+langchain+studio.py`：Redis + LangChain + Studio

**四增强（1个）**：
- `标准链路+agent+redis+langchain+studio.py`：全部增强

### 3.2 叠加顺序

当叠加多个增强时，按以下顺序应用：

1. **Step 1（初始化）**：
   - 如果有 Redis 增强，先添加 Redis 配置
   - 其他增强不影响初始化

2. **Step 2-3（重置和显示配置）**：
   - 如果有 Agent 增强，改为 `for_agent`
   - 其他增强不影响

3. **Step 4-6（服务操作）**：
   - 如果有 Agent 增强，改为 `for_agent`
   - 如果有 Studio 增强，修改服务配置格式
   - 其他增强不影响

4. **Step 7（工具调用）**：
   - 如果有 LangChain 增强，替换整个步骤
   - 如果有 Agent 增强，改为 `for_agent.call_tool`
   - 其他增强不影响

5. **Step 8-9（配置显示和清理）**：
   - 如果有 Agent 增强，改为 `for_agent`
   - 其他增强不影响

### 3.3 组合示例

**Agent + Redis 组合**：
```python
# Step 1: Redis 配置 + Agent 变量定义
agent_name = "demo_agent"
redis_config = RedisConfig(...)
store = MCPStore.setup_store(debug=False, cache=redis_config)

# Step 2-9: 所有操作使用 for_agent
store.for_agent(agent_name).add_service(...)
store.for_agent(agent_name).list_tools()
# ...
```

**Agent + Studio 组合**：
```python
# Step 1: Agent 变量定义
agent_name = "demo_agent"

# Step 4: Studio 服务配置
service_config = {
    "mcpServers": {
        "mcpstore-wiki": {
            "command": "python",
            "args": ["/path/to/script.py"],
            "env": {}
        }
    }
}
store.for_agent(agent_name).add_service(service_config)
```

**Redis + LangChain 组合**：
```python
# Step 1: Redis 配置
redis_config = RedisConfig(...)
store = MCPStore.setup_store(debug=False, cache=redis_config)

# Step 7: LangChain 流程
tools = store.for_store().for_langchain().list_tools()
# ...
```

## 4. 注意事项

1. **变量命名**：
   - Agent 模式必须定义 `agent_name` 变量
   - Redis 模式使用 `redis_config` 变量
   - 保持变量命名一致性

2. **导入顺序**：
   - 先导入 `example_utils`
   - 再导入 `mcpstore`
   - 最后导入增强相关模块（如 `RedisConfig`、`ChatOpenAI`）

3. **打印信息**：
   - 所有打印信息保持英文
   - 在关键步骤说明使用的增强模式
   - 保持树形结构输出格式

4. **错误处理**：
   - 保持标准链路的错误处理方式
   - 不添加额外的 try-except（除非必要）

5. **配置来源**：
   - Redis 配置统一使用 `ExampleConfig`
   - LLM 配置统一使用 `ExampleConfig.get_llm_config()`
   - 服务路径可以硬编码，但建议使用配置

## 5. 检查清单

创建新的增强版本时，检查以下项目：

- [ ] 文件名符合命名规范
- [ ] 导入语句正确（包含所有需要的模块）
- [ ] Step 1 初始化正确（如有 Redis，添加 cache 参数）
- [ ] Step 2-3 正确（如有 Agent，使用 for_agent）
- [ ] Step 4-6 正确（如有 Agent，使用 for_agent；如有 Studio，修改配置格式）
- [ ] Step 7 正确（如有 LangChain，替换整个步骤；如有 Agent，使用 for_agent）
- [ ] Step 8-9 正确（如有 Agent，使用 for_agent）
- [ ] 所有打印信息为英文
- [ ] 保持树形结构输出格式
- [ ] 变量命名一致
