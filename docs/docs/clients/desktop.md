# 桌面端与 Web

桌面端和 Web 使用同一套界面能力。本页默认以桌面端说明；Web 只在启动方式不同的地方单独标注。

## 桌面端

桌面端用于直接在本机查看和管理 MCP 服务。桌面端界面与 Web 共用服务管理页面。

桌面端特有内容：

- 安装和启动桌面应用
- 窗口大小与系统窗口行为
- 本地后台运行

## Web

Rust CLI 可以启动 Web 管理界面：

```bash
mcpstore web --config-path ./mcp.json
```

默认监听 `127.0.0.1:8080`。可以指定地址和端口：

```bash
mcpstore web --host 127.0.0.1 --port 8080 \
  --config-path ./mcp.json
```

Web 与桌面端共用服务管理能力；访问地址和部署环境不同于桌面端时，以实际启动参数为准。
