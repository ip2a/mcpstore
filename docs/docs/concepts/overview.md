# MCPStore 是什么

MCPStore 是一个用于统一管理 MCP 服务的工具。

它不负责管理 Agent。它管理的是 MCP 服务本身，以及这些服务当前是否可用、提供了哪些能力。

## MCPStore 能做什么

- 保存和修改 MCP 服务配置
- 启动、停止、重启和删除服务
- 查看服务状态并执行健康检查
- 发现服务提供的 Tool、Prompt 和 Resource
- 为本地程序、编程助手或其他 MCP 客户端提供接入
- 管理本地实例，或连接远程实例

## 不同使用入口

CLI、TUI、桌面端、Web、Rust 和 Python 是不同的使用入口，不是不同的产品。它们共享同一套核心概念；具体操作方式会因入口不同而变化。
